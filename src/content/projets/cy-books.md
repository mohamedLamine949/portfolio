## Réalisations

- Application de gestion développée en Java EE / Spring, avec l'ORM Hibernate.
- Intégration de l'API REST de la BnF pour compléter automatiquement les fiches des ouvrages.

## Environnement technique

Java EE, Spring, Hibernate, API REST.
